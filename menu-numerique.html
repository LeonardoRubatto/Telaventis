Aussi pour la restauration

Un menu numérique, affiché via un QR code sur chaque table.

Le même principe qu'un site une page, appliqué à la carte d'un restaurant, café ou bar : les clients scannent un code posé sur la table et voient le menu du jour dans leur propre navigateur — rien à installer, rien à télécharger.

Discuter d'un menu numérique →

Ce que vous obtenez

Toujours à jour
Prix et plats se changent dans un tableau simple, la carte se met à jour partout.
Sans application
Le QR code ouvre une page web classique dans le navigateur du client.
Un code par table
Prêt à imprimer, il pointe toujours vers la même carte à jour.
Plusieurs langues
Français, anglais ou italien, comme le reste d'un site Telaventis.

Comment ça se met en place

01Le menu est structuré

Plats, prix, catégories et langues, organisés avec vous.

02La page est écrite

Une page rapide, lisible sur téléphone, à l'identité de votre établissement.

03Le QR code est généré

Prêt à imprimer sur chaque table ou présentoir.

04Vous mettez à jour vous-même

Un tableau simple suffit pour changer un prix ou un plat du jour.

Combien ça coûte ?

Un menu numérique se traite comme un site une page, en plus simple : à partir de 450 €, en une fois. Les solutions du marché tournent plutôt autour de 15 à 35 € par mois, sans fin — ici, c'est payé une fois et le site vous appartient, rien d'autre à payer ensuite, sauf si vous choisissez le suivi mensuel, à 5–10 €. Le périmètre exact est toujours fixé par écrit avant de commencer.
