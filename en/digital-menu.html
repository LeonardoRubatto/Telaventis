The same principle as a one-page site, applied to a restaurant, café or bar menu: customers scan a code on the table and see today's menu right in their own browser — nothing to install, nothing to download.

What you get

Always current
A price or daily special changes in a simple spreadsheet, the menu updates everywhere.
No app

One code per table
