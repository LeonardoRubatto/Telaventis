What you get

  • Always current.

    A price or a daily special changes? Say so and the menu is updated everywhere — no need to reprint the QR code.

  • No app.

    The QR code opens an ordinary web page in the customer's own browser.

  • One code per table.

    Ready to print, always pointing to the same up-to-date menu.

  • Multiple languages.

    French, English or Italian, like the rest of a Telaventis site.
